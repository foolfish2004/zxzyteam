# 武汉各区县逐年 SHAP 与表格汇总说明

生成日期：2026-10-17

## 一、这个文件夹里有什么

| 目录 | 内容 |
| --- | --- |
| `01_区县SHAP/` | 武汉 13 个区 + 全市汇总的逐年 SHAP 统计（长表、宽表、格网匹配统计） |
| `02_表格CSV/` | 三尺度模型、SHAP、趋势、环带与跨尺度一致性汇总表 |

## 二、区县 SHAP 表是怎么算的

1. 取每个尺度的格网中心点（EPSG:32650 米制坐标），用 `pyproj` 转换为 WGS84 经纬度。
2. 与武汉 13 个区的行政边界（`wuhan_datav_full.json`）做点面叠置。边界经过简化，少量落在边界外的格网按“最近面”归入相邻区，并在 `区县格网匹配统计.csv` 中单独记录。
3. 对每个“区县 × 年份 × 因子”，计算该区所有格网—年 SHAP 的均值与平均绝对值。
4. 同时给出“武汉市”一行，作为全市参照。

匹配情况：990 米 8,430/8,517 个格网落在面内（99.0%），1500 米 3,695/3,741（98.8%），3000 米 941/956（98.4%）；其余为最近面归属，不影响区级均值的量级。

## 三、字段怎么读

| 字段 | 含义 |
| --- | --- |
| `尺度` | 990米 / 1500米 / 3000米 |
| `区县` | 13 个区，另加“武汉市”全市汇总 |
| `年份` | 事件年 2017–2025 |
| `因子` | 九个驱动因子 |
| `平均SHAP` | 该区该年该因子 SHAP 的算术平均，保留原始响应量纲 |
| `平均SHAP_标准化` | 除以本尺度响应标准差，单位为“响应标准差”，可跨尺度比较 |
| `平均绝对SHAP` | 平均绝对 SHAP，衡量归因强度而不看方向 |
| `平均绝对SHAP_标准化` | 同上，除以本尺度响应标准差 |
| `格网数` | 该区该年参与统计的格网数（各区之和等于该尺度总格网数） |

**量纲提醒**：990 米与 1500 米的响应是比例（0.0156 = 1.56%），3000 米是百分点（1.54 = 1.54%）。跨尺度比较请用带“标准化”的列。

## 四、初步读数

以 1500 米、2025 年为例：

- **生境质量的归因强度在中心城区最高**：硚口区 0.88、江汉区 0.84、武昌区与汉阳区 0.61、江岸区 0.61（平均绝对 SHAP，响应标准差单位）。
- **夜间灯光的归因强度在汉阳区、硚口区、青山区最高**（0.22、0.22、0.20）。
- **医院核密度的负向归因集中在江汉区（−0.58）与硚口区（−0.55）**，对应中心城区“医院最密、已经建满”的饱和段。
- **学校核密度的正向归因同样在江汉区（0.65）与硚口区（0.59）最高**。

SHAP用于解释模型预测相对于背景值的贡献。平均绝对SHAP描述归因强度，有符号SHAP描述相对于背景值的贡献方向。

## 五、区县表的两个版本

- **长表**：一行 = 尺度 × 区县 × 年份 × 因子，适合筛选、画图和建模。
- **宽表**：一行 = 尺度 × 区县 × 年份，9 个因子的平均 SHAP 与平均绝对 SHAP 并排，适合直接查看和做透视表。
