# 数据索引说明

## 模型与残差

| 文件 | 说明 |
| --- | --- |
| `model_summary_three_scales.csv` | 三尺度主模型汇总（R² 均值/标准差/最差折、RMSE、MAE） |
| `model_1to1_summary.csv` | 合并折外样本的 1:1 拟合 R²、斜率、平均残差 |
| `990_model_summary.csv`、`1500_model_summary.csv`、`3000_model_summary.csv` | 各尺度八类模型完整汇总 |
| `990_moran_summary.csv`、`1500_moran_summary.csv`、`3000_moran_summary.csv` | 折外残差全局 Moran's I（k=8 邻域，199 次置换） |

## SHAP

| 文件 | 说明 |
| --- | --- |
| `shap_importance_by_scale.csv` | 九因子平均绝对 SHAP 与归因份额 |
| `entropy_summary.csv` | 三尺度平均归因熵、主导因子及其覆盖比例 |
| `shap_pdp_summary.csv` | PDP 曲线的 Pearson 相关、p 值、过零点、过零以上样本占比 |
| `shap_ring_sector_profiles.csv` | 环带 × 12 扇区的平均绝对 SHAP 剖面 |
| `990_shap_mk_summary.csv`、`1500_shap_mk_summary.csv`、`3000_shap_mk_summary.csv` | SHAP 的 MK 趋势摘要（τ 均值/中位数、Sen 斜率、FDR 显著比例） |

## SHAP 跨尺度与空间统计

| 文件 | 说明 |
| --- | --- |
| `shap_contribution_summary.csv` | 各尺度、因子的平均绝对SHAP |
| `cross_scale_agreement.csv` | SHAP贡献层的跨尺度空间一致性 |
| `feature_level_rank_agreement.csv` | SHAP贡献层的因子排序一致性 |
| `spatial_dispersion.csv` | SHAP贡献层的空间分布与符号统计 |
| `multiscale_comparison.md` | 三尺度模型表现汇总 |
