# 武汉城市扩张研究结果数据

版本日期：2026-10-29

本仓库仅包含研究结果数据与结果图件，不包含网页平台、正式报告、论文草稿、中间计算文件或运行环境。

## 研究范围

- 研究区：武汉市。
- 时间范围：2016-2025 年。
- 空间尺度：990 m、1500 m、3000 m。
- 分析内容：不透水面扩张、扩张模式与方向、热点与趋势、模型评价、SHAP 归因、区县统计、fuzzy GD 与空间汇总。

## 目录

- `00_documentation/`：数据说明、字段说明和文件校验清单。
- `01_tables/`：模型评价、SHAP、区县统计、形态、方向、扩张、fuzzy GD 等表格。
- `02_spatial/`：行政边界、开发边界、扩张强度、热点、SHAP 空间格网及统计汇总。
- `03_figures/`：与上述结果对应的最终图件。

## 数据格式

- 表格：UTF-8 CSV；必要时保留原始 XLSX。
- 矢量：GeoJSON，统一使用 WGS84（EPSG:4326）展示坐标。
- 栅格：GeoTIFF，原始分辨率和坐标信息以文件内元数据为准。
- 图件：PNG 为主，部分保留 PDF 或 SVG。

## 使用说明

1. `00_documentation/FILE_MANIFEST_SHA256.csv` 给出除清单自身外全部文件的相对路径、大小和 SHA256。
2. 区县 SHAP 长表和宽表均保留，长表适合筛选与建模，宽表适合直接查看。
3. 模型指标只在同一空间尺度内比较；跨尺度分析使用标准化后的 SHAP 结果。
4. 栅格文件用于结果展示和复核，不应脱离原始坐标与分辨率单独解读。
5. 本数据包不包含原始遥感影像和完整可再训练数据，因此不能单独用于重新训练模型。

## 引用与口径

数据字段与研究口径详见 `00_documentation/DATA_DICTIONARY.md` 以及来源说明。公开发布前请按实际论文署名、项目资助和引用要求补充引用信息。
